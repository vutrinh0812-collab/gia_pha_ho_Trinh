# Phông chữ cho file PDF (D72)

Các phông này được nhúng vào file PDF khi bấm "Tải PDF khổ A1" ở trang In ấn. Chúng chỉ được tải về khi xuất PDF, không tải khi xem app.

Nguồn: Google Fonts. Đã cắt chỉ giữ chữ Latin và tiếng Việt (`pyftsubset`), không còn hinting và bảng layout.
